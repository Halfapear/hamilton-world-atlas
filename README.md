# Hamilton World Atlas｜汉密尔顿世界巡演图鉴

这是一个只服务于《Hamilton / 汉密尔顿》的交互式世界地图与购票准备工具，不包含其他音乐剧、演唱会或通用演出数据。

## 当前版本

- 数据核验日期：2026-10-28
- 4 个制作板块：纽约百老汇、北美巡演、伦敦西区、韩国世界巡演
- 22 个当前／即将演出站点：纽约 1 个、北美巡演 18 个、伦敦 1 个、韩国 2 个
- 3 个区域：北美、欧洲、亚洲
- 地图与站点层级：世界 → 区域 → 制作版本 → 城市 → 场馆 → 官方售票页面
- 仅在官方来源确认时填写演出期间、开票时间和票价；其他地区不猜测票价或余票

## 在 Windows 上运行

1. 下载项目 ZIP 并解压到你指定的文件夹，例如：
   `D:\Onedrive\OneDrive - Queen Mary, University of London\桌面\大四\文学\汉密尔顿`
2. 双击 `启动汉密尔顿世界图鉴.bat`。
3. 默认打开 `http://127.0.0.1:8765/index.html`。本机需要 Python 3。
4. 如果端口 8765 已被占用，先关闭已有本地服务器，或在 BAT 中更改端口号。

应用是本地静态网页，不需要安装 Node、数据库或第三方 JavaScript 库。官方售票链接需要联网。

## 如何更新数据

- 编辑 `data/hamilton-world.json`。
- 每个站点必须有唯一 `id`，并且 `productionId` 必须指向 `productions` 中已存在的制作版本。
- 只新增有官方来源支持的 Hamilton 站点；不要将历史演出自动视为当前在售。
- 在项目目录运行 `python tools/build.py`，重新生成自包含的 `index.html`。
- 地图站点数、区域计数、列表和筛选会从 JSON 自动更新，不需要逐处改写计数。

`src/index.template.html` 是界面模板，`index.html` 是生成后的可运行文件，`data/hamilton-world.json` 是编辑用的数据源。

## 购票边界与安全

- 应用提供官方信息发现、购票准备、个人计划、日历文件和 JSON 备份；它不是售票商。
- 账号登录、选座、支付与订单确认都在官方售票平台完成。本应用不收集第三方密码、验证码或银行卡资料。
- 北美各城市的售票商和票价可能不同；从官方巡演页选择城市，再点击该城市的 Get Tickets / Get Info。
- 韩国场的票价已由官方公布；其他地区不在应用中填入未核实价格。
- 当前未接入实时座位、余票、第三方账号代理登录、订单同步或支付 API；这些能力需要售票平台授权。
