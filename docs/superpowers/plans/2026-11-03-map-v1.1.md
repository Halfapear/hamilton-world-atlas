# World Map v1.1 Implementation Plan

**Goal:** Correct the world map without changing the 22 verified stops, ticket information, or stored personal plans. Iterate in the existing directory and upload the verified changes to the existing GitHub history.

**Architecture:** Embed a local Natural Earth coastline into the self-contained HTML at build time. Land, routes, and markers use the same equirectangular projection. Keep dots at geographic coordinates, use offsets only for labels, and fit the viewport to the selected region.

**Tech Stack:** Static HTML/SVG/JavaScript, Python build tool, Python Playwright, Microsoft Edge.

## Confirmed defects

- Hand-drawn continents do not share the point projection; New York and Korea are displaced from land.
- `dx`/`dy` shift dots by tens of map units, including Busan far offshore.
- Zoom changes the viewport around the global center instead of the selected region.
- Entering a region changes state without refreshing map filters when returning.
- Existing tests hard-code Linux Chromium and check only marker counts/viewBox changes.
