## 关键交互验证

- 点击伦敦地图标记可打开伦敦详情，并可进入伦敦制作版本，再返回伦敦站点。
- 点击亚洲区域卡片可进入区域层，再进入韩国世界巡演，再进入首尔站点。
- 首尔站可打开 NOL 韩国站商品页；釜山站明确标注官方公告不等于实时选座页。
- 选择 VIP 两张时预算显示 ₩440,000；数量改为三张后更新为 ₩660,000（均不含手续费）。
- 超出演出期间的意向日期会被拒绝；有效日期可以保存。
- 计划导出为 `hamilton-world-atlas-plan.json`，提醒导出为 `.ics` 文件。

## 测试限制

本执行环境禁止浏览器直接导航到本地 HTTP 地址，因此 Playwright 将生成的 HTML 内容载入测试页面后运行脚本与交互检查。它验证了 Chromium 中的 DOM、JavaScript 和用户交互，但不等同于在真实 Windows 电脑上验证 BAT 启动脚本。项目压缩包包含 `启动汉密尔顿世界图鉴.bat`，建议首次运行时按 README 操作。

测试脚本：`tests/test_app.py`。运行需要 Python Playwright 与可用 Chromium：`python tests/test_app.py`。
