执行环境的 Chromium URL 管理策略阻止打开本地文件和本地 HTTP 页面，因此本次未声称完成真实 Chromium 的截图/像素级视觉验收。以上是可重复的应用逻辑和交互 smoke tests，不等于真实售票系统端到端测试。
